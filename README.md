# 42.195km、なのに。

**走る、バカになる、東京をめぐる。**

東京を 42.195km 走るマラソンゲーム。
ただし走っている途中で、カメラ・世界・ゲームジャンル・映像表現まで次々と変わっていく。
それでもプレイヤーがやることは最後まで「前へ走って、ゴールを目指す」だけ。

ジャンル: 東京 × マラソン × デジタル × バカゲー（Three.js / ブラウザ）

## 現在の状態: Vertical Slice（0〜5km）

西新宿（都庁前）スタート → 新宿 → 新宿三丁目 → 市ヶ谷 → 飯田橋ゴールの 5km。道はカーブし、速いほど外側へふくらむ。

- 0.0km 普通の 3D マラソン（255 人の AI ランナーと一斉スタート）
- 0.8km 声援が増えてくる
- 1.2km **TV 中継カメラ**（ヘリ・沿道・正面望遠・中継バイク、LIVE テロップ）
- 2.2km **突然真横 2D**（ドット絵化 + チップチューン）
- 2.9km **猫が横切る**（ジャンプで飛び越えると NYAN JUMP）
- 3.1km **外濠沿いで電車と競争**（ダッシュで総武線を追い抜け）
- 3.9km **柴犬 3 匹が伴走**（そばを走ると WAN! ボーナス）
- 4.1km **赤信号**（止まれば MANNERS ボーナス、無視すると車が来る）
- 4.4km **猫の大移動**
- 4.5km **東京、読み込み中**（街がワイヤーフレームに）
- 4.6km **巨大柴犬**（ビジョンから出てきてコースをまたぐ）
- 4.9km 最後の直線は普通のマラソン → 5.0km 仮ゴール → リザルト

## 遊び方

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開く。

| 操作 | キー |
| --- | --- |
| 横に移動 | ← → / A D |
| ペース（上げる / 落とす）・赤信号で止まる | ↑ ↓ / W S |
| ジャンプ | SPACE |
| ダッシュ（スタミナ消費） | SHIFT |
| 音 ON/OFF | M |
| 一時停止 | P / ESC |

スマートフォンでは画面下のボタンで操作できる。

### 声援（CHEER）

速さだけでなく「どれだけ大会を盛り上げたか」がスコアになる。

- 先頭を走るほど注目される（1 位は毎秒大きく加算）
- 追い抜き・ギリギリ回避・ランナー飛び越え・障害物ジャンプ・転倒からの復帰
- 柵ぎりぎりを走って観客とハイタッチ
- ライバル（忍者ランナー）との競り合い
- 連続するとコンボで倍率アップ

CHEER が増えると観客が腕を上げ、跳ね、スマホのフラッシュが光り、紙吹雪が舞う。

### URL パラメータ（開発用）

| パラメータ | 内容 |
| --- | --- |
| `?debug` | FPS・draw call・距離などを表示 |
| `?auto` | 自動操縦で自動スタート（通しプレイ確認用） |
| `?fast=4` | シミュレーションを N 倍速で進める（検証用） |
| `?warp=2.1` | スタート後に指定 km へワープ |
| `?mute` | 無音 |

## 構成

設計・調査報告は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

- 依存は `three` と `vite` のみ
- 画像・音声ファイルは使わず、テクスチャは Canvas、音は WebAudio で生成
- イベントは `src/data/vertical-slice.json` で距離ごとに定義（データ駆動）

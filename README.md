# 42.195km、なのに。

**走る、バカになる、東京をめぐる。**

東京を 42.195km 走るマラソンゲーム。
ただし走っている途中で、カメラ・世界・ゲームジャンル・映像表現まで次々と変わっていく。
それでもプレイヤーがやることは最後まで「前へ走って、ゴールを目指す」だけ。

ジャンル: 東京 × マラソン × デジタル × バカゲー（Three.js / ブラウザ）

### 声援（CHEER）

速さだけでなく「どれだけ大会を盛り上げたか」がスコアになる。

- 先頭を走るほど注目される（1 位は毎秒大きく加算）
- 追い抜き・ギリギリ回避・ランナー飛び越え・障害物ジャンプ・転倒からの復帰
- 柵ぎりぎりを走って観客とハイタッチ
- ライバル（忍者ランナー）との競り合い
- 連続するとコンボで倍率アップ

CHEER が増えると観客が腕を上げ、跳ね、スマホのフラッシュが光り、紙吹雪が舞う。

## 800m、なのに。（新作・2〜4 分）

**2周だけなのに、何回ゲーム変わるの？**

`800m/` の別ページ（タイトルの 3 枚目のカード、または ← → で選んでスタート）。12 人・400m トラック 2 周の決勝。
レース（RaceCore）は最後まで本物の陸上のまま、見た目・カメラ・HUD・音・観客・時間・ジャンルが「Modifier」で次々に壊れて、**重なる**。

| m | 流れ |
| --- | --- |
| 0〜80 | 普通の陸上（位置について、よーい、号砲） |
| 80〜120 | 最初の小さな異変（一人だけ巨大な観客 / スコアボードが鏡文字） |
| 200〜 | 少しずつ増える（同時に 1〜2 個） |
| 400 | 鐘と同時に大きく変わる（カメラ + 見た目 + 観客をいっぺんに） |
| 600 | いちばん混沌（3〜5 個が重なる。なのにCOMBO） |
| 720 | 最大のイベント（ジャンルごと変わる・世界がねじれる …） |
| 760 | すべて消える → 770 画面が普通 → 780 UI は残り距離だけ → 790 音楽が消える |
| 800 | 足音と呼吸と歓声だけの本気の 40m。写真判定（0.01 秒） |

- Modifier は **83 種類**（VISUAL / CAMERA / WORLD / PHYSICS / RUNNER / CROWD / UI / TIME / AUDIO / GENRE / LEGENDARY）。組み合わせで「なのに文」が自動で作られる（例:「巨人の侍が鏡の中でTV中継されているのに。」）
- 1〜3% のレースだけ LEGENDARY（観客全員がランナーに / 競技場ごと宇宙へ / 画面が 4 分割 / 最後の 100m だけ PS1）
- 同じ seed なら同じレース・同じ演出（結果画面に SEED と「THIS RACE HAD:」）
- 操作: `W` `S` / `↑` `↓` ペース、`A` `D` / `←` `→` レーン、`SPACE` 足音に合わせて（リズムで効率アップ）、`SHIFT` スパート、`F1` 開発パネル、`M` 音。スマホはスティック + RUN / BURST

800m の URL パラメータ: `?seed=5124` `?autopilot=1`（`naive` で下手な自動操縦）`?distance=400` `?modifier=fisheye,giant,tv` `?camera=tv` `?chaos=1`（0 で演出なし）`?legendary=space` `?fast=4` `?quality=low|medium|high` `?mute=1` `?debug=1`

自動テスト（Playwright はグローバルのものを使う。依存には追加していない）:

| コマンド | 内容 |
| --- | --- |
| `npm run smoke` | 起動 → 自動操縦で 40 秒 → console error と Modifier 定義の食い違いを確認 |
| `npm run race-test` | 複数 seed で完走し、順位・タイム・演出の順番を記録（`--determinism` で同じ seed の再現性も確認） |
| `npm run filmstrip` | 0〜700m とゴールのスクリーンショット一覧 |
| `npm run gallery` | 全 Modifier / 組み合わせ（`--combo=giant+tv+mirror`）を 1 枚ずつ撮って一覧に |
| `npm run benchmark` | 画質 × 混沌度ごとの FPS・draw call・三角形数 |
| `npm run mobile` | スマホ縦・横の画面 |

設計は [800m/ARCHITECTURE.md](800m/ARCHITECTURE.md)（新しい Modifier の足し方も）。

## トランポリン、なのに。（新作・5〜8 分）

**数秒しかない滞空時間に、ゲームを詰め込みすぎる。**

`trampoline/` の別ページ（タイトルの 4 枚目のカード、または ← → で選んでスタート）。男子個人決勝、10 回の試技の合計で競う。
見た目は最後まで真面目なスポーツ中継（審判 5 人・E スコア・得点板・実況）。狂うのは画面の中身だけ。

1. ベッドが沈む瞬間に `SPACE`（スマホはタップ）で踏み込む → ベッドが深く沈んで、ヒットストップ・低い音・観客の「おおっ」
2. 跳んだ瞬間、世界がスロー（0.05〜0.3 倍）。カメラは顔へ寄る。UI とタイピングは普通の速さのまま
3. 出てきた英単語をタイピングすると技になる。途中まででも回る（`F` 少し / `FL` 半回転 / `FLI` 3/4 / `FLIP` 1 回転）。速く打つと FLIP FLIP FLIP とつながる
4. 回りきってから着地。着地の出来・技・入力・偶然の一致・観客・カメラ・事故・なのに の 8 部門で採点（失敗しても点は入る）

| 単語 | 技 |
| --- | --- |
| FLIP / POWER | 宙返り（抱え込み）/ 屈身 2 回宙返り |
| SPIN / TWIST | ピルエット / ひねり |
| POSE / BALLERINA | 大の字 / **バレリーナ**（クラシックが流れ、世界がさらに遅く、映画のようなカメラ） |
| HIGH / SLOW | 空中なのにもう一度跳ぶ / 自分で時間を遅くする |

テンポ: 第 1〜2 試技は普通 → 3〜4 少し変（顔しか映らない / 花火と一致 / バレリーナ）→ 5〜6 かなり変（カメラが選手を見失う / 速すぎて見えない / 飛行機と重なる / 観客も跳ぶ）→ 7〜8 意味不明（観客席のドラマ / 一人だけ飛びすぎ）→ 第 9 試技で**天井 OPEN**（屋根が左右に開いて夜空）→ 超反発 10m → 30m → 50m → **空へ**（街 → 雲 → 空 → 成層圏 → 宇宙。それでも HUD は ATTEMPT 9/10 のまま）→ `←` `→` で会場の真上に合わせて帰る → **PERFECT RETURN +10,000** → 屋根は何事もなかったように閉まり、審判は普通に採点する。

- 背景（花火・飛行機・鳥・取材ヘリ・照明・観客ウェーブ・フラッシュ）は選手と関係なく勝手に動いていて、頂点・回転・ポーズ・着地と偶然重なると加点
- 演出はすべてデータ（`trampoline/src/data/events.js` の表、29 件）。表に 1 行足すだけで増やせる
- 操作: `SPACE` 踏み込み、`A`〜`Z` 空中タイピング、`←` `→` 空から帰る時の位置、`ESC` ポーズ、`M` 音。スマホはタップ + 文字ボタン（次の文字 + まぎらわしい 3 文字）+ ◀ ▶

URL パラメータ: `?attempt=9`（その試技から）`?event=ROOF_OPEN,BALLERINA`（強制発生）`?seed=3` `?auto`（自動操縦）`?cps=6`（自動操縦の打鍵速度）`?fast=2` `?mute` `?debug`

| コマンド | 内容 |
| --- | --- |
| `npm run tramp:smoke` | 自動操縦で 10 試技を最後まで → console error・イベント表の食い違い・見せ場が全部起きたかを確認 |
| `npm run tramp:shots` | 自動プレイしながら一定間隔でスクリーンショット（`--query=&attempt=9` `--width=390 --height=844`） |

設計は [trampoline/ARCHITECTURE.md](trampoline/ARCHITECTURE.md)（再利用した部品・時間の分け方・イベントの足し方・空の旅の仕組み）。

## サッカー、なのに。（新作・Vertical Slice 約 4 分）

**10 万人の中から自分の席を探していたら、試合が終わった。**

`soccer/` の別ページ（タイトルの 5 枚目のカード、または ← → で選んでスタート）。男子サッカー決勝 日本 vs ブラジル。
プレイヤーは選手ではなく、少し遅刻した観客。チケットの座席番号がにじんで読めない。係員いわく「お客様のお席だけ、空いております。」

- **論理 100,000 席**（ちょうど）のスタジアムから、空いている 1 席を探す。10 万人は 1 draw call のビルボード（遠くは 2 色・近くは形を描く）+ 主人公のまわりだけ 3D の人形
- ドラッグで見回す・タップで調べる・長押しで候補 A B C・ダブルタップ（B キー）で双眼鏡（4〜8 倍、ピンチ / ホイールで倍率）
- 肉眼では反対側の席は小さすぎて調べられない → 隣の客が双眼鏡を貸してくれる。ヒント（チケットの色 → 場内放送 → 大型ビジョン → にじんだ列）で `100,000 → 70,464 → 17,744 → 11,108 → 1,774 席` と絞れる
- 空席っぽく見えるのは本物 1 つ + デコイ約 600（トイレの人の席・荷物・子供・座席と同じ色の服で寝ている人）
- 試合は本当に進行している（22 人・普通の速さ・時計だけ速い）。決定機で観客が前のめり、シュートで立ち、ゴールで跳ぶ → **試合が面白くなるほど空席が見えなくなる**。ウェーブが空席を順番に隠していく
- ゴールの瞬間は目の前で旗が振られ、大型ビジョンは巨大な GOOOOOAL!! が映像を隠し、リプレイは始まった直後に広告になる
- 見つけたら反対側まで走る（連打）。やっと座った瞬間、前の人が立ち上がり、前半終了の笛。結果に `MATCH WATCHED` と `GOALS ACTUALLY SEEN 0 / 4`

後半・ハーフタイムの空席激増・望遠鏡・AI SEAT DETECTOR は次の段階。

URL パラメータ: `?skip`（オープニングを飛ばす）`?seed=3` `?quality=high|medium|low|verylow` `?debug`（FPS・draw call・三角形）`?auto&findAt=150`（自動操縦）`?warp=100` `?fast=2` `?mute`

| コマンド | 内容 |

| `npm run soccer:smoke` | 自動プレイで結果画面まで → 10 万席・本物が 1 つ・ピックの命中率・NaN・console error を確認 |

設計は [soccer/ARCHITECTURE.md](soccer/ARCHITECTURE.md)（10 万人の描き方と実測比較・座席の解析的な逆算・公平性・試合と席探しの連動・スマホ対策）。

## ボクシング、なのに。（新作・約 9 分・4 ラウンド）

**試合はちゃんとしてる。ゲームがちゃんとしてない。**

`boxing/` の別ページ（タイトルの 6 枚目のカード）。世界タイトルマッチ 4 ラウンド、赤コーナー 侍 vs 青コーナー 王者。
相手・HP・ラウンド・時間はずっと同じ試合のまま、**ボクシングのゲームシステムだけが次々に変わる**。操作は最後まで同じ（A D / ← → でよける・動く、J 左、K 右、L ガード、SPACE アッパー）。

- ゲームシステム 13 種: 普通の 3D → 正面固定カウンター（相手は常にガード・よけた直後だけ通る）→ 横スクロール（A D が前後）→ 真上の作戦盤（A D で回り込む）→ 一人称 → リズムゲーム（拍に合わせると 2 倍）→ 8BIT → QTE → スーパースロー → テレビ中継 → 監視カメラ → 観客のスマホの縦動画 → 超望遠 ×400
- ROUND 1 は時刻で（25 秒で最初の変化）。合間に中継のハプニング（タイトル表示の遅れ・カメラが天井のビジョンを映す・今さらチュートリアル・紙吹雪の誤発射・一瞬 8BIT・撮影スタッフが横切る・停電・まちがった BGM・時計が 88:88）、ROUND 2 は「慣れた瞬間」に変わる（15 秒たって 4 回うまくいったら）、ROUND 3 は中継・監視カメラ・スマホ・望遠 + CM（L 字でも試合は続く）、FINAL は 2 つ重ね（横スクロール × 8BIT など）→ `???`（3 秒ごと）→ 最後は 3D
- 相手のパンチは必ず予備動作（テル）を見せる + 「!」の予告。紙一重でよけると PERFECT → カウンター 2 倍
- HYPE（会場がおかしくなるゲージ）: よけた・カウンター・紙一重・ダウンから立った・システムが変わった・打ち合い で上がる → 観客が立つ → 総立ち → スマホのフラッシュ → ウェーブ → 跳ぶ、光の筋・カメラの台数・紙吹雪・風船
- 周りがどんどん騒がしくなる: 情報パネル（パンチ数 → 心拍数 → 会場の湿度・好きな食べ物・ゴング係の緊張・Wi-Fi …）、実況（熱い → どうでもいい話）、テロップ、リプレイ（1 → 2 → 4 → 8 → 16 分割・拳カメラ・床カメラ・天井・魚眼・超スロー・巻き戻し・白黒）、小窓の中継
- 選手・レフェリー・勝敗は茶化さない（笑いはゲームシステム・カメラ・中継・会場・UI から）。KO（FINAL のダウン）か 3 人のジャッジの判定で決まる

URL パラメータ: `?skip`（入場を飛ばす）`?round=3`（そのラウンドから）`?sys=side` / `?sys=fps,rhythm`（システムを固定）`?auto`（自動操縦）`?fast=4` `?quality=high|medium|low|verylow` `?debug` `?nofx` `?mute`

| コマンド | 内容 |
| --- | --- |
| `npm run boxing:smoke` | 自動操縦・8 倍速で入場 → 4 ラウンド → KO / 判定 → 結果まで。console error を確認 |
| `npm run boxing:systems` | 13 種のシステムを順に切り替えてスクリーンショット |

## 棒高跳び、なのに。（新作・約 3 分 + エピローグ）

**視聴率が、あなたの記録になる。**

`polevault/` の別ページ（タイトルの 7 枚目のカード）。夜の陸上競技場（ちょうど 30,000 席）で、男子棒高跳び決勝の最後の 3 分間を生中継する。
プレイヤーは選手ではなく、**出来高制のテレビカメラマン**（給料 = 視聴率）。競技は最後まで真面目な棒高跳び。笑いの対象はカメラマンの視線。

- 3 万人の観客席では、同時にたくさんの人生が進んでいる（母親・秘密の恋人・審判と元妻・会社を休んだ姉・昔のコーチ・ポップコーンを落とす人・間違った国旗・鳥のカップル・月・流れ星・猫 …）。物語の候補は **105 本**、1 プレイで 10〜13 本が同時に起きる。全部は撮れない

- 普通に競技を撮るだけでも視聴率は取れる（助走を追う +150・ポールがしなる +250・バー越え +800 …）。でも、観客席で母親が祈っている

- 3 分後、エピローグで「あなたが撮った映像」の意味が変わる（「彼女は、選手の母親だった。」）。撮らなかった物語は明かさない

## 競歩、なのに。（新作・約 7 分）

**ちゃんと歩けば勝てる。でも、ふざけた方が配信は伸びる。**

`racewalk/` の別ページ（タイトルの 8 枚目のカード）。登録者 15 万人の競歩配信者・アユム（架空）として、男子 10000m 競歩決勝の残り 5 周（2000m）を**生配信しながら**歩く。

画面は 3 つ: **左 = 配信者の誘惑（ACTION / REACTION）** / **中央 = 真面目な競歩（3D・配信の映像）** / **右 = 勝手に騒ぐインターネット（LIVE CHAT）**。

- 競歩はちゃんとしたレース: ↑↓ でペース（5 段）・←→ で横（追い越し・給水）・SPACE でつまずきを立て直す / 給水を取る。前の人の真後ろは風よけ、カーブの外は損、上げすぎると浮く（ロス・オブ・コンタクト）、疲れると膝が曲がる。審判 6 人の黄色パドル → 赤カード（3 枚でペナルティゾーン 30 秒・4 枚で失格）。真面目に歩けば優勝できる
- 疲れはゲージに出ない。腕が下がる・頭が揺れる・歩幅が縮む・ふらつく・息が荒くなる。そして**コメント欄**が「腕下がってない？」「顔死んでるぞ」「普通に元気そう」と言い合う
- 左の ACTION は状況で 3〜6 個（通常・疲れてる？・つまずいた・アンチ・スパチャ・ラスト 1 周・ペナルティ・ゴール後・失格）。押さなくてもいい。でも「アンチ太郎に反応する」「立ち止まってスパチャを読む」「走る」「ここで寝たふりをする」が光って出てくる。コメント欄の「押せ / 押すな」の人数も見える
- 右の LIVE CHAT は約 230 人の視聴者（ViewerNPC）。古参・新規・ガチ勢・アンチ・擁護・小学生・心配性・スパチャ常連・冷静・喧嘩・初見・切り抜き・海外・ルール警察・ROM専・コメ欄観察 …。人格の数値・記憶（2 回目は言い方が変わる）・関係（因縁）を持ち、出来事に反応し、勝手に喧嘩する（「どっちでもいいから競歩見ろ」→「そもそも今 6 位だぞ」→「6 位なの？」→「誰も競技見てなくて草」）
- コメント欄の小さな物語が同時に進む: 古参と新規の喧嘩と休戦・アンチ太郎の最後の「……がんばれ」・初見がメンバーになる・41 か月 ROM 専の初コメ・アユムの母（本物）・石油王と十万円の男・がんばれおじさん
- 炎上は失敗でも成功でもない: 同接・スパチャ・登録者が伸びる。アンチ・低評価も増え、審判の注目が上がり、集中が切れてつまずく。同接は 2 万 → 最大数百万
- RESULT: 競歩の順位・最大同接・登録者・スパチャ総額・高評価/低評価・炎上回数・審判の警告・転倒・コメント総数・推定切り抜き再生数。正解は出さない（自動操縦の目安: 真面目 = 1 位・同接 7 万・+1 万 / バランス = 2〜4 位・同接 40〜65 万・+6〜8 万 / 炎上 = 最下位・同接 350 万超・+40 万超）

URL パラメータ: `?start` `?auto=serious|balance|flame`（自動操縦）`?seed=3` `?t=300`（早送り）`?fast=4` `?cam=back` `?norender` `?quality=high|medium|low|verylow` `?mute`

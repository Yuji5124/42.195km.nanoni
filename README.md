# 42.195km、なのに。

**走る、バカになる、東京をめぐる。**

東京を 42.195km 走るマラソンゲーム。
ただし走っている途中で、カメラ・世界・ゲームジャンル・映像表現まで次々と変わっていく。
それでもプレイヤーがやることは最後まで「前へ走って、ゴールを目指す」だけ。

ジャンル: 東京 × マラソン × デジタル × バカゲー（Three.js / ブラウザ）

## 現在の状態: Vertical Slice（0〜10km）

西新宿（都庁前）スタート → 新宿 → 市ヶ谷 → 飯田橋 → 水道橋 → 秋葉原 → 神田 → 日本橋ゴールの 10km。
道はカーブし、速いほど外側へふくらむ。

## 遊び方

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開く。

| 操作 | キー |
| --- | --- |
| 横に移動 | ← → / A D |
| ペース（上げる / 落とす）・赤信号で止まる | ↑ ↓ / W S |
| ジャンプ（シューティング中は射撃） | SPACE |
| ダッシュ（スタミナ消費） | SHIFT |
| 音 ON/OFF | M |
| 一時停止 | P / ESC |

スマートフォンでは画面下のボタンで操作できる。

### 声援（CHEER）

速さだけでなく「どれだけ大会を盛り上げたか」がスコアになる。

- 先頭を走るほど注目される（1 位は毎秒大きく加算）
- 追い抜き・ギリギリ回避・ランナー飛び越え・障害物ジャンプ・転倒からの復帰
- 柵ぎりぎりを走って観客とハイタッチ
- ライバル（忍者ランナー）との競り合い
- 連続するとコンボで倍率アップ

CHEER が増えると観客が腕を上げ、跳ね、スマホのフラッシュが光り、紙吹雪が舞う。

### URL パラメータ（開発用）

| パラメータ | 内容 |
| --- | --- |
| `?debug` | FPS・draw call・距離などを表示 |
| `?auto` | 自動操縦で自動スタート（通しプレイ確認用） |
| `?fast=4` | シミュレーションを N 倍速で進める（検証用） |
| `?warp=2.1` | スタート後に指定 km へワープ |
| `?mute` | 無音 |

## 構成

設計・調査報告は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

- 依存は `three` と `vite` のみ
- 画像・音声ファイルは使わず、テクスチャは Canvas、音は WebAudio で生成
- イベントは `src/data/vertical-slice.json` で距離ごとに定義（データ駆動）

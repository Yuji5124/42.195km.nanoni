# 棒高跳び、なのに。 — 設計

> 記録を跳ぶのは選手。物語を見つけるのはカメラマン。視聴率が、あなたの記録になる。

タイトル画面の 7 枚目のカード（`src/core/Game.js` の `EXTERNAL.polevault` → `polevault/index.html#from-main`）。
`#from-main` の時だけ「← タイトルへ」を出す。直接開いても単体で動く。

プレイヤーは選手ではなく、**出来高制のテレビカメラマン**（給料 = 視聴率）。3 分間（180 秒）の生中継の間、
3 万人の観客席・審判・鳥・月・照明……の中から「何をテレビに映すか」を選び続ける。その選択が、その日の中継の物語になる。

## 1. 流れ

```
title → live（0:00〜3:00）→ offair（3 秒）→ epilogue（2〜4 本・各 7〜9 秒）→ result
          0:00  夜のスタジアム・環境音・主人公の独り言（「今月ちょっと厳しいんだよな。」）
          0:09  ディレクター「本番 5 秒前。」→ 0:12.5 ON AIR（LIVE / VIEWERSHIP 12.4% / PAY ¥0 / CHEERS 0）
          0:15〜 試技 10 本（競技を理解する → 背景の異変 → イベント密集 → クライマックス → 最後の 10 秒）
```

| 時刻 | 競技（Competition） | 同時に起きること（例: seed による） |
| --- | --- | --- |
| 0:15〜0:50 | ケラー 5.80 ○ / 高嶺 5.80 ○ / リヴァ 5.80 ○ | 子どもが立つ・幼なじみの看板・姉は仕事のメール |
| 0:50〜1:30 | サラス 5.90 ×（敗退）/ 高嶺 5.90 ○ | 2 羽の鳥が入ってくる・月が雲から出る・審判長が客席を見る・母が祈る |
| 1:30〜2:15 | ケラー 5.90 ×（敗退）/ リヴァ 6.00 ○ / 高嶺 6.00 ○ | 鳥が月の前を横切る・恋人が別の選手を見ている・審判長と元妻の目が合う |
| 2:15〜2:50 | リヴァ 6.05 ×（3 回目）→ **高嶺の優勝が決まる** | 母が立ち上がる・プロポーズ・昔のコーチが腕を組んだまま泣く |
| 2:50〜3:00 | 高嶺 6.05（大会新記録に挑戦。まれに世界記録の高さ）| 会場が静まる・スマホのライト・鳥が夜空へ・**月がちょうどバーの上** |

## 2. 分け方

```
                    ┌────────── 時刻で決まる（プレイヤーは変えられない）──────────┐
 PoleVaultMode ──▶  Competition（10 本の試技・バー・記録）   StoryDirector（物語 8〜13 本・拍・ヒント）
     │               └ Vaulter × 4（関節モデル + しなるポール）  └ SpecialCrowd（物語の人・審判・スタッフ 70 人前後）
     │              NightSky（月・雲・星・飛行機・流れ星）・Birds（2 羽）・CrowdDirector（3 万人の姿勢）
     │
     └─ プレイヤーのもの: BroadcastCamera（パン/ティルト/ズーム/ピント/ロック）
                 │ 毎フレーム
                 ▼
          Subjects.frame()  何が・どれくらいの大きさで・どこに・ピントが合って映っているか（ゲームの中の情報）
                 │
                 ├─▶ ShotJudge.tick()      0.25 秒ごとの「テレビとしての質」q → 視聴率 → Cheers
                 ├─▶ Commentary.onCamera()  「……カメラが観客席へ。」「鳥ですね。」「鳥です。」
                 └─▶ SHOT（Space）/ ロック 3 秒 → ShotJudge.evaluate() = 8 つの値 × AI の倍率
                                                 + 実際の画像の解析（analyzePixels）
```

## 4. カメラの気持ちよさ（BroadcastCamera）

- 入力は「ヘッドを押す」。角度は臨界減衰に近いばね（固有振動数 15 → 望遠端 7）で遅れてついてくる = 重い望遠レンズ
- マウス 1px で回る角度は画角に比例（望遠でも狙いやすい）。Shift で 2.6 倍
- ズーム: 対数で慣性（サーボの速さ 2.6 / 秒、R の広角は 9 / 秒）。1〜50 倍
- ピント: 距離は対数で遅れて合う。AF は画面の中央の被写体（→ 地面 → スタンドの面 → 空）をゆっくり追う。右クリックで素早く合わせ直す。ロック中は対象を追う
- 被写界深度は望遠ほど浅い（`aperture = 0.0016 × zoom^1.25`）。ピントの合っていない SHOT は点数が下がる
- ロック: 対象を中央へ少しずつ引き寄せる（完全には固定しない）。1.5 秒見失うと外れる
- 急パン: 画面の流れ（パンの向きに 6 点）+ 揺れ（望遠ほど目立つ）+ パンのこすれの音

## 5. 視聴率と採点（ShotJudge）

視聴率 `v = 床(t) + bonus`。床は 12.4% から終盤へ向けて +5.2%（大会が盛り上がるほど自然に見られる）+ 優勝・記録の瞬間の一時的な上乗せ。
`bonus` は「いまの画面の質 q」で増え、24 秒ほどで抜ける。SHOT の点数でも跳ねる（1 秒で 1.2% 以上 = VIEWERSHIP SPIKE）。

| いま映っているもの | q の目安 |
| --- | --- |
| 試技の最中の選手（助走 0.75 / ポール 1.15 / バー越え 1.25 / 着地 0.8）| 大きさがちょうどよく、中央にあるほど高い |
| 物語の人（拍の面白さ v 0〜1.5）| 同じ人を長く映すと飽きる（10 秒） |
| 鳥（月の前を横切る時 1.15）・月（0.42）・照明 | 夜空は 12 秒を過ぎると下がり始める |
| 審判（0.16、JUDGE BIAS 中は +0.25）・スタッフ・ただの観客 | 少しだけ |
| 試技の最中に選手を映していない | −0.5（物語のカットなら −0.22） |
| 急パン・ピンぼけ | −0.3 × ブレ / × ピント |

SHOT の点数 = sports + composition + timing + emotion + story + beauty + rarity + unexpected（× AI の倍率 × ピント × ブレ × 飽き）。
競技の値は指示どおり（助走を綺麗に追う +150・ポールがしなる +250・上昇 +300・バー越え +800・美しい空中姿勢 +600・着地 +250・選手の笑顔 +400・優勝決定 +1,500・大会記録 +2,500・世界記録 +5,000）。
構図: 選手＋月 +1,500 / 選手＋照明 +800 / 観客の涙＋競技 +1,000 / 鳥＋月 +900 / 夜空＋スタジアム +400。
**MASTER SHOT**: バーを越える瞬間の選手 + バー + 月（+ 涙を流す人か鳥 = MIRACLE）。

### AI CAMERA JUDGE（少しおかしい）

ゲームの中の情報（何が映っているか・物語の拍）+ 実際の画像の解析（`analyzePixels`: 160×90 に縮めたキャンバスの
ラプラシアンの分散 = 鮮明さ・コントラスト・Hasler & Süsstrunk の彩り・明るい点の割合）+ ゲーム用の乱数。

- 世界記録・大会記録を綺麗に撮っても 86〜90 で止まる（`SPORT VALUE STANDARD`）
- 夜空だけ: `VERY BEAUTIFUL` で 90 台 / 審判のアップ: `HE LOOKS THOUGHTFUL` で 90 台 → 実況「なぜこんなに高いのでしょうか。」
- 審判ばかり撮ると `JUDGE BIAS: ON`（審判に甘くなる）/ 同じものを 3 回続けると `BORING`
- ときどき関係のない行（`SANDWICH (3%)`・`GRAVITY: PRESENT`・`CAMERAMAN: TRYING`）
- サムネイルには検出の枠（athlete 0.97 / person 0.81 / moon 0.99 / bird 0.88）

### Cheers・給料

`Cheers = Σ 視聴率 × 秒 × 8 + 点数 × 0.3`。
今日の給料 = 基本給 ¥30,000 + 平均視聴率 × ¥2,600 + 最高視聴率 × ¥1,000 + 物語の SHOT × ¥3,500 + 撮った物語 × ¥6,000 + 競技の SHOT × ¥1,500 + MASTER SHOT ¥40,000〜。
最後の一言: 平均 24% 以上「……今日は飯食えるな。」/ 17% 以上「まあ、なんとか。」/ それ以下「来月どうしよう。」

## 6. 観客 3 万人

| 層 | 人数 | 描き方 |
| --- | --- | --- |
| 遠く・中くらい | 30,000（ビルボード）| soccer の `CrowdField`（1 draw call・画面の大きさで LOD）。姿勢は `CrowdDirector` の DataTexture（ブロック 44 個）|
| 特殊 NPC | 約 85（物語 15〜25 + 審判・スタッフ 11 + ただの観客 55。撮影台の真後ろの 7 列に 30 人）| `Figure`（SkinnedMesh・1 人 1 draw call・表情・視線・小物）。その席のビルボードは空席にする |

soccer の `NearCrowd`（箱の人形）は使わない: カメラの真後ろ 3〜8m の席は振り返るとすぐ目の前で、箱の人形は粗く見え、顔のある `Figure` とも合わない。
そこはビルボード（スタジアムのほかの観客と同じ絵柄）+ 顔のある `Figure` を多めに混ぜた（`?near` で NearCrowd を有効にして比べられる）。

観客の反応はブロック単位: 手拍子（儀式で求められると、助走に向けて速くなる）→ 前のめり → 半分立つ → 成功で歓声・拍手 / 失敗で頭を抱える → 座る。
最後の試技の前は会場が静かになり、カーブとバックスタンドでスマホのライトが灯る。大会新記録で全員が跳ぶ。

## 7. 物語（データ駆動）

- `story/stories.js` + `stories2.js` に **105 本**（family / romance / comedy / sad / judge / athlete / staff / bird / nature / random）。表に 1 つ足すだけで増やせる
- 1 プレイで 10〜13 本（鳥と夜空はいつも。母は 7 割。家族 1〜2・恋 1・審判 1〜2・悲しい or 選手 1・くだらないもの 3〜4・その他 2〜3）。`conflicts` で同時に出ないものを除く
- 拍（beat）の時刻は秒・物語の開始から（`'+4'`）・試技の時刻（`'takane#2.run-1'` = 高嶺の 2 本目の助走の 1 秒前）。`if: 'clear' | 'fail'` で結果に合わせて出し分け
- 座る場所はゾーンで指定（`barLine` = カメラから見てバーの向こう。クライマックスにバー・月と同じ画面に入る / `nearMain` = 撮影台の真後ろ / `mainUpper` / `back` / `backUpper` / `curveE` / `curveW` / `front`）。隣どうし（`pair`）も
- 弱いヒントだけ: 反射光（スマホ・双眼鏡・涙）/ 立ち上がる / こちらを向く / 小さな声 / 主人公の「ん？」/ ごく薄い枠（1.4 秒）。巨大な矢印は出さない
- 撮っている時だけ聞こえる客席の声（`say`: 指向性マイク）と、撮った時の実況（`onAir`: 説明しすぎない）
- 見逃しは失敗ではない（結果に `Missed Moments` として数えるだけ）

## 8. エピローグ

撮った物語（SHOT・ロックの評価で拍を撮ったもの）から、点数・重要な拍・大きな物語かどうかで 2〜4 本。夜空は最後（「中継の最後の映像として使われた」）。
足りなければ競技の場面（「その瞬間、あなたのカメラは別の場所を見ていた。」）。場面ごとに人を動かし（母は一番前の手すりへ・高嶺はその下で手を伸ばす / 二人は選手のトンネルの前 / 審判と元妻は手すりごしに / 姉は帰っていく / 鳥は月の方へ）、
自分の撮った映像を VTR として左上に出す。最後に「この日、あなたが知らない物語も、まだ 27,941 人分あった。」（数字は毎回変わる）。観客は少しずつ帰っていく。

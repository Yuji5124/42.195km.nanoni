# 競歩、なのに。— 設計メモ

> ちゃんと歩けば勝てる。でも、ふざけた方が配信は伸びる。

『42.195km、なのに。』のタイトル画面の 8 枚目のカードから入る別ページ（`racewalk/index.html#from-main`）。
ほかの別ページの競技（800m・トランポリン・サッカー・ボクシング・棒高跳び）と同じ作り: タイトル（`src/core/Game.js` の `EXTERNAL`）がページを移動し、RESULT の「タイトルへ戻る」で戻る（タイトルから来た時は `history.back()` でタイトルの状態を残す。そうでなければ `../index.html` を開く）。

## 画面の 3 つ

| 左 ACTION / REACTION | 中央 3D 競歩（配信の映像） | 右 LIVE CHAT |
| --- | --- | --- |
| 配信者の誘惑 | 真面目な競歩 | 勝手に騒ぐインターネット |
| `stream/ActionSystem.js` + `stream/actions.js` + `ui/ActionPanel.js` | `race/RaceSim.js` + `scene/*` + `walk/Gait.js` + `ui/StreamHUD.js` | `chat/*` + `ui/ChatView.js` |

基本ループ: **右 → 左 → 中央 → 右**

- 右（アンチ太郎「こいつ競歩下手じゃね？」）→ 左に「アンチ太郎に反応する」が出る
- 左（押す）→ 中央（気が散る・速度が落ちる・フォームが崩れる）+ 配信の数字（同接・炎上）
- 中央（つまずく・抜かれる・腕が下がる）→ 右（「今ふらついたぞ」「つまずいただけ」「信者必死で草」）

## レース（RaceSim）

- 10000m 競歩の 8000m 通過（31:46.2）から残り 5 周。約 7 分（等速・実時間）。
- プレイヤーの操作は ペース（5 段: 4.15〜5.08 m/s）・横・SPACE（立て直す / 給水）。
- 余力 E（0〜1・画面に出さない）: `drain = 0.0005 + 0.0025·max(0, v − (vSus − 0.65))² + 0.02·max(0, v − (vSus + 0.17))²`。前の人の真後ろは ×0.88。給水で回復。しゃべると少し減る。
- 浮き lc: `(v − (4.8 + 0.34·E)) / 0.45`。膝 bk: `(0.3 − E) / 0.3 × 0.55`。ACTION（変な歩き方・お辞儀・元気アピール・走る）で増える。
- 審判 6 人（周回の決まった場所）。前を通る時のフォーム（1.4 秒の平均）で黄色パドル → 赤カード（同じ審判から 1 枚まで）。炎上・ピースで審判の注目が上がる。赤 3 枚 → 次にペナルティゾーンで 30 秒、4 枚 → 失格。
- つまずき: 疲れ・気が散る（コメントを見る等）・炎上・前の人のかかとで起きやすい。SPACE が間に合えば「つまずき」、間に合わなければ「転倒」（約 3 秒）。
- AI: 集団のペース + 戦術（真壁は残り 1200m で揺さぶり、各自 kickAt でスパート、ピンチャは前半に飛ばして赤カードをもらいやすい）。
- 調整: 真面目な自動操縦（集団のペース・風よけ・給水・残り 300m でスパート）は 6 回中 6 回優勝、ただ巡航すると 4〜7 位。

## 配信の数字（StreamingMetrics）

```
同接 = 20,300 × e^R × (1 + 盛り上がり)
  R: 出来事の buzz を足す（届いている範囲が広いほど効きにくい・1 回の上限あり）
     炎上 heat が続く間は伸び続ける（上限に近づくほど伸びない）
     何も起きない・背中しか映っていない時は少しずつ下がる（一度来た人の一部は残る = 床）
  盛り上がり: 上位 × 接戦 × 終盤（0〜1）
heat（0〜12）: アンチに反応・言い返す・寝たふり … で上がり、放っておくと冷める
               → 3 / 6 / 9 で 小炎上 / 炎上 / 大炎上。審判の注目・つまずきやすさに効く
trust（0〜1）: 真面目・結果で上がり、肝心なところでふざけると下がる（低いとファンが離れる）
登録者・スパチャ（ポアソン・炎上で大きい額と荒らしが増える）・評価・コメント総数・推定切り抜き再生数 は流れで決まる
```

ACTION の buzz は「飽き」（同じものは 0.58 倍ずつ）と「タイミング」（ラスト 1 周・上位・つまずいた直後は大きい）で変わる。

`npm run rw:balance` の目安（6 シード）:

| 遊び方 | 順位 | 最大同接 | 登録者 | スパチャ |
| --- | --- | --- | --- | --- |
| 真面目 | 1 位 | 7 万 | +1 万 | 約 25 万円 |
| バランス | 2〜4 位 | 40〜65 万 | +6〜8 万 | 35〜50 万円 |
| 炎上 | 最下位 | 350〜400 万 | +40〜45 万 | 約 160 万円 |

どれも正解とは言わない（RESULT の最後の一言は結果の組み合わせで変わるだけ）。

## コメント欄（LiveChatSystem）

- 視聴者 約 230 人（名前のある 26 人 + 人格ごとに名前を作った人）。毎フレームは全員を動かさない。
  1. **出来事への反応**: レース・ACTION・数字のイベント（TRIP / FALL / WAVE / READ_CHAT / IGNORE_ANTI / OVERTAKE / OVERTAKEN / SUPERCHAT / RED / FATIGUE / DENY_FATIGUE / TROLL_ACTION / SLEEP_FAKE / BELL …）→ その出来事に合う人格の人を数人（同接と炎上で増える）選んで、遅れて書き込ませる。
  2. **何もない時のおしゃべり**: 表示の速さに合わせて 1 人ずつ（レースの段階 × 人格のセリフ）。
  3. **小さな物語**（arcs.js）・**言い合い**（2〜6 往復 → 「どっちでもいいから競歩見ろ」→「そもそも今 6 位だぞ」→「6 位なの？」→「誰も競技見てなくて草」）・**押せ / 押すな**（光っている誘惑ごとに人数を数え、いちばん新しい誘惑についてだけ声に出す）。
- 記憶: 同じ出来事の 2 回目は言い方が変わる（「今ふらついたぞ」→「ほら疲れてる」）。「疲れてない」派は証拠を見るたびに揺れ（doubt）、折れる（「今日はちょっと怪しい」→「古参折れてて草」）。同じセリフは最近使われていないものを選ぶ。
- 関係: もち ⇔ ぴよ、アンチ太郎 ⇔ くま、アンチ ⇔ 擁護 …（言い合いの相手の選び方）。
- 台本で動く人（がんばれおじさん・ROM専・石油王・十万円の男・母・モデレーター）はふだんの抽選に入らない。名前のある人は、自分らしい反応がある出来事にしか反応しない。
- 表示の速さ: 1.5 件/秒（通常）→ 4（小炎上）→ 9.5（炎上）→ 21（大炎上）+ 同接 + ラスト。上限を超えた優先度の低いコメントは「流れて見えなかった」扱いで間引く。スパチャ・名前のある人・事件のコメントは必ず出す。速すぎる時は「注目」欄にも出す。
- LLM は使わない（データ + 人格の数値 + 記憶 + 乱数）。

### セリフ・物語・ACTION の足し方

- セリフ: `lines.js` の `EVENTS[出来事][人格]` に配列（または `{ first, again }`）を足す。`{pos}` `{gap}` `{rem}` `{anti}` などが差し込める。
- 物語: `arcs.js` に `{ id, steps: [{ if(x), do(x), gap }] }` を足す。`x.say(id, text, { delay, hl })` `x.antiSay` `x.superchat` `x.join` `x.system`。
- ACTION: `actions.js` に足す（`ctx` で出る状況、`when(c)` で条件、`race` / `stream` で効果、`event` でコメント欄へ）。`event` に合うセリフを `lines.js` に足す。

## 3D（RaceWalkScene）

- 競技場は棒高跳びの StadiumBuilder を継承（`buildVaultArea` を上書き）: フィニッシュライン・周回板と鐘・レースの時計・警告掲示板（赤カードが出ると描き直す）・審判の机 6 つ・給水所・ペナルティゾーン・LED 広告・大型ビジョン（上位 5 人）。
- 観客 30,000 人は soccer の CrowdField（ビルボード 1 draw call）。主人公の近くのブロックが拍手 → ラストは総立ち → ゴールで跳ぶ。ACTION「観客をあおる」で跳ぶ。
- 人は Figure（1 人 1 draw call・表情アトラス）: 選手 10・審判 6（黄色パドルを持つ）・係・カメラマン。
- 競歩の動き（Gait.js）: 位相 φ から脚（接地から垂直まで膝を伸ばす・蹴り出し・遊脚で膝を曲げる）・足首・骨盤のひねりと傾き・逆にひねる胸・肘 90° の腕振りを作る。疲れ・浮き・膝・ACTION（手を振る・スマホ・ペンギン歩き・お辞儀・寝たふり・転倒・後ろ向き・走る）を重ねる。
- カメラ: 配信ドローン（顔・斜め前。間に選手が入ったら内側 / 外側へ回る）/ 追走（背中・前が見える。C で切り替え。コメント欄は「顔映して」）/ 真壁 / 寝たふり（真上）/ フィニッシュの横 / ペナルティ。
- 影は主人公のまわりだけ（光源ごとついていく）。描画は中央の欄の大きさだけ。

## パフォーマンス

- draw call 約 90・約 13.5 万三角形（観客 3 万人を含む）。PerformanceGovernor が FPS を見て pixelRatio・alpha-to-coverage を下げる。
- コメントの DOM は最大 46 件を使い回す（スパチャのピン 6・注目 2・通知 4 まで）。1 フレームに来た大量のコメントは新しい 10 件だけ描く。
- 視聴者は出来事の時だけ選ばれる（全員を毎フレーム更新しない）。

## テスト

- `npm run rw:balance` … Node だけ（描画なし）で 3 つの遊び方 × 6 シード。`-- --chat=flame --seed=1` でコメント欄の全文。
- `npm run rw:smoke -- --auto=balance` … ブラウザで RESULT まで。`--back` でタイトルのカードから入って RESULT の「タイトルへ戻る」でタイトルに戻るまで。`--retry` で「もう一度配信する」。`--shot=result.png`。
- `npm run rw:shot -- --q="start&seed=3&t=409"` … スクリーンショット（`--clip=x,y,w,h` `--touch --w=390 --h=844`）。
